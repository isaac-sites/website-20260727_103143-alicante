## Introduction

The official Spanish UFO archive is the most important evidence trail for judging [Segovia]({{ 'segovias-ufo-stories-between-claims-and/' | relative_url }})’s place in Spain’s UFO history. It does not provide proof of extraordinary craft, but it does show which reports reached military investigators, what information was collected, and how authorities attempted to explain unusual aerial observations. For Segovia, the archive is significant mainly because it helps separate documented investigations from local stories that survive through testimony, press reports or later retellings. The available record suggests a province with UFO interest but without a large, nationally recognised archive of unexplained military cases.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

Spain’s main documentary source is the former Air Force collection known as the *Expedientes OVNI* (UFO files). These files are valuable because they contain investigation summaries, witness information, technical notes and final assessments. They also show an important distinction: an official investigation means that authorities examined a report, not that they accepted an unusual explanation for it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## Spanish Air Force UFO files

The Spanish Ministry of Defence began releasing these files after a declassification process that started in the early 1990s. The material was later digitised through the Biblioteca Virtual de Defensa, making it available for public consultation. The collection contains around 80 files and roughly 1,900 pages covering reports from across Spanish airspace between 1962 and 1995 where Air Force personnel, facilities or information were involved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

For researchers studying Segovia, the value of the archive is not simply whether a famous case appears under the province’s name. The more important question is what kind of evidence survives. A formal file may include:

* the date and location of the observation;
* summaries of what witnesses reported;
* interviews or statements;
* weather information;
* military observations where available;
* conclusions about possible [explanations]({{ 'explanations-1b2cc5/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

This structure makes the archive useful for evaluating claims. A newspaper report saying that someone saw an unusual light is a record of a claim. A military file adds another layer: it shows whether the event was checked, what information investigators considered, and whether a conventional explanation was proposed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

The archive’s searchable catalogue also allows researchers to examine records by location, including province-related searches. This matters for Segovia because it provides a way to test whether a local story corresponds to a documented investigation rather than relying only on later summaries or folklore.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/busqueda.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## What the archives show about Segovia records

Segovia’s position in the official record appears limited compared with provinces associated with better-known Spanish UFO investigations. The absence of a major, widely discussed Segovia file in the public Air Force collection does not mean that no unusual sightings occurred in the province. It means that the strongest nationally preserved documentary trail is not built around a recognised Segovia case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

This distinction is important because UFO histories often combine several different types of material:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* a witness memory recorded years later;
* a newspaper article describing a sighting;
* a report by a private UFO researcher;
* a government investigation file.

</div>

These sources do not have the same evidential weight. A government archive can confirm that officials investigated an event, but it cannot automatically confirm the interpretation attached to the sighting. The Spanish files themselves include conclusions and classifications, showing that investigators frequently treated unusual observations as problems of identification rather than evidence of unknown technology.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

For Segovia, this creates a more cautious historical picture. The province fits the wider Spanish pattern of UFO reporting: occasional observations of lights or objects that attracted public attention, but a much smaller documentary footprint than the most famous national cases.

## Investigations and explanations

The main lesson from the Spanish files is that investigation often reduced uncertainty rather than increased mystery. Reports that initially appeared unusual could later be connected with aircraft, astronomical objects, weather conditions or other ordinary causes. Similar patterns appear in other countries’ official UFO archives, where many reports were eventually linked to conventional explanations after further analysis.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nationalarchives.gov.uk/explore-the-collection/explore-by-time-period/postwar/ufo-reports/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nationalarchives.gov.uk">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nationalarchives.gov.uk</span><span class="citation-popover-title">National Archives UFO reports</span><span class="citation-popover-snippet">National ArchivesUFO reports - The National Archives...</span></span></span>

The Spanish Air Force approach was therefore closer to an identification process than a search for confirmation of extraordinary theories. Investigators examined what was seen, when it was seen and what information could explain it. When evidence was incomplete, cases could remain unresolved without becoming proof of anything beyond the limits of the available data.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

This matters when assessing Segovia stories. A report involving a bright object, unusual movement or an apparently silent aircraft may feel convincing to a witness, but reliable interpretation depends on additional evidence: independent observers, radar information, photographs, flight records or physical data. Without those elements, the archive-based assessment usually remains one of uncertainty rather than confirmation.

## Limits of the available record

The Spanish UFO archive is an important historical resource, but it is not a complete record of every sighting in Spain. It mainly reflects cases that entered official channels, particularly those involving the Air Force or aviation-related concerns. A local sighting reported only to newspapers, private investigators or community groups may never appear in the government collection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

There are also limits within the released documents themselves. Although the files were made public, some personal details of witnesses and officials were removed. This protects privacy but can make later historical reconstruction more difficult.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

For Segovia, the result is a balanced conclusion. The archives provide a reliable way to check whether a reported event received official attention, but they do not reveal a hidden catalogue of confirmed unexplained incidents.     var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
