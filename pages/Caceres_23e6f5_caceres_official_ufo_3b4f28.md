## Introduction

Spain’s declassified military UFO archive is surprisingly sparse for Cáceres. Among the 80 case files made publicly available by the Ministry of Defence, the province has one clear documentary anchor: a 37-page Air Force intelligence file concerning observations by aircraft near Montánchez on 3 June 1967. The national catalogue contains no comparable run of named Cáceres investigations, radar cases or later provincial dossiers.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>



<img src="{{ "/assets/images/Caceres_23e6f5_caceres_official_ufo_3b4f28-overview.webp" | relative_url }}" alt="Overview image for Official Files" loading="eager" decoding="sync" fetchpriority="high">

That does not prove that nothing else was reported in Cáceres. It shows something narrower but important: only a small amount of provincial material entered, survived within and was later released from the military reporting system. The archive therefore provides a benchmark for assessing later stories. Claims from places such as Valencia de Alcántara, Ceclavín or other rural districts may still be worth examining, but they should not be described as officially investigated military cases unless supporting records can be produced.

## How Spain built its public UFO archive

The Spanish Ministry of Defence began reviewing classified records of “strange phenomena” in 1991, responding to public pressure for access. A physical copy of the collected material was deposited in the Air Force Central Library in Madrid in 1992, and the files were later digitised for the Defence Virtual Library. The official collection now comprises 80 files and about 1,900 pages, covering incidents from San Javier in 1962 to Morón in 1995.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

These were not simply newspaper cuttings assembled into a national catalogue of every Spanish UFO report. The collection concerns incidents in which Air Force personnel, equipment or administrative channels were involved in some way. A report was more likely to leave an official trail when it reached an air command, concerned an aircraft, involved a military unit or was formally passed to the aviation authorities.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

The files also vary greatly in quality and size. The Defence Virtual Library says that a typical dossier may contain summary sheets, witness interviews, incident logs, weather reports and conclusions, but some consist of only a few pages while others contain dozens. Names of witnesses and reporting officers are withheld even after declassification.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/micrositios/inicio.do" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

This matters when judging Cáceres. The archive is best understood as a surviving Air Force administrative collection, not a census of everything unusual reported in the province.

### Why the catalogue shows 83 titles but 80 files

The online title index currently contains 83 entries, although the official introduction describes 80 UFO files. The difference is largely administrative rather than evidence of three hidden cases. The final entries include an interview, an article about the released files and a collection of military regulations, while the index also contains a separate chronological listing of dossiers.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/indice_campo.do?campo=idtitulo" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

Readers should therefore avoid counting every catalogue title as a distinct sighting. For provincial comparisons, the relevant question is how many actual incident dossiers name or materially concern the province.

## Where Cáceres appears in the index

The principal Cáceres entry is titled, in translation, “Sighting of strange phenomena by aircraft in flight over Montánchez (Badajoz): 3 June 1967”. It was produced by the Operational Air Command’s intelligence section, runs to 37 pages and includes illustrations or charts. The Chief of the Air Staff authorised its declassification on 25 September 1992.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/busqueda_referencia.do?campo=idtitulo&amp;idValor=396030" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

The catalogue’s geography is internally awkward. Montánchez is in Cáceres province, yet the title places it in Badajoz. The record itself assigns both Badajoz and Cáceres as associated locations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/busqueda_referencia.do?campo=idtitulo&amp;idValor=396030" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

That mismatch could have arisen from an error in the original paperwork, the route or position of the observing aircraft, or later cataloguing. The available metadata does not settle which explanation is correct. What it does demonstrate is that searches based only on exact province names can miss relevant material. A researcher looking only for “Cáceres” in titles might overlook the province’s most important official case because “Badajoz” appears in the heading.

The national title index reinforces the impression of scarcity. It contains many individually named cases from Madrid, the Canary Islands, Barcelona, Navarra, the Balearic Islands and other areas, but only the Montánchez aviation dossier is plainly tied to Cáceres in the incident list. Nearby Extremaduran records, such as cases at Talavera la Real, the Talavera air base or Usagre, are catalogued under Badajoz and should not automatically be absorbed into Cáceres UFO history merely because they occurred in the same autonomous region.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/indice_campo.do?campo=idtitulo" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## What the Montánchez file establishes

The strongest point in favour of treating Montánchez seriously is institutional rather than extraordinary. The report concerned aircraft in flight and was handled by an Air Force intelligence section. Its 37-page length indicates that more than a passing note survived in the archive.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/busqueda_referencia.do?campo=idtitulo&amp;idValor=396030" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

That gives the case a firmer documentary footing than a recollection first published decades later. It establishes that:

It does not, by itself, establish an extraterrestrial craft, advanced technology or even a permanently unexplained event. An intelligence file can be opened because an observation might affect flight safety, airspace control or national defence. “Unidentified” describes a failure to identify a stimulus from the available information; it does not identify the stimulus as exotic.

The catalogue metadata also cannot replace close examination of the pages. A reliable reassessment would need the original witness accounts, aircraft positions, headings, times, weather information, possible astronomical objects and any calculations or diagrams. Until those elements are tested together, detailed retellings of the object’s shape, speed or intentions should be treated with caution.

## Why the official record may be incomplete

The absence of additional Cáceres files has several possible explanations, none of which can be proven from the index alone.

Some reports may never have reached military authorities. A light seen by residents and discussed locally would not necessarily trigger an Air Force inquiry, especially if it posed no obvious aviation or defence concern. Other observations may have been reported informally but never developed into a classified dossier.

Records can also be lost before central archiving. Specialist researcher Vicente-Juan Ballester Olmos, who was closely involved in encouraging the Spanish declassification process, has argued that the released collection represents cases located in central and regional military repositories, not every incident in which aviation personnel may once have taken an interest. He states that some information remained at unit level or was never forwarded to Air Force headquarters. That interpretation is consistent with the archive’s institutional character, although it comes from a participant in the process rather than from a complete official audit of missing files.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ovniteca.net/sites/default/files/2024-08/expedientes_desclasificados_online.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ovniteca.net">[Ovniteca]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ovniteca.net</span><span class="citation-popover-title">expedientes desclasificados online</span><span class="citation-popover-snippet">Source details in endnotes.</span></span></span>

There is also a chronological limit. The public archive ends with an incident dated 1995, but Spanish military procedures for handling unusual aerial reports did not simply cease at that point. In a 2022 freedom-of-information response, the Air Force said that Instruction 40-5 governed the receipt, reporting, classification and custody of such cases. It stated that dossiers were treated as confidential until declassified and held by the Intelligence Section of the Air Combat Command.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.defensa.gob.es/Galerias/main/2022/07/resolucion-68360anonimizada.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: defensa.gob.es">[Ministerio de Defensa de España]</a><span class="citation-popover" role="note"><span class="citation-popover-source">defensa.gob.es</span><span class="citation-popover-title">resolucion 68360anonimizada</span><span class="citation-popover-snippet">resolucion 68360anonimizada</span></span></span>

A further Defence response published in 2023 repeated that reports remain classified until a declassification decision is made and said that the reports declassified up to that date had been placed in the Defence Virtual Library.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.defensa.gob.es/Galerias/main/2023/04/20230420-Resolucion-76770.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: defensa.gob.es">[Ministerio de Defensa de España]</a><span class="citation-popover" role="note"><span class="citation-popover-source">defensa.gob.es</span><span class="citation-popover-title">20230420 Resolucion 76770</span><span class="citation-popover-snippet">20230420 Resolucion 76770</span></span></span>

These responses mean the public database should not be treated as proof that no post-1995 military reports exist. Equally, they do not demonstrate that undisclosed Cáceres cases exist. They establish only that the reporting system allowed later material to remain confidential unless formally released.

## What missing files can and cannot tell us

Cáceres’s sparse showing is evidence about documentation, not about the absolute frequency of unusual experiences. It supports three cautious conclusions.

**The province was not a major centre of surviving military UFO paperwork.** Compared with areas represented by repeated aviation, radar or air-defence dossiers, Cáceres has one principal released case.

**Later local accounts require independent sourcing.** A story does not gain official status simply because it occurred during the period covered by the national archive. Contemporary press reports, police records, diaries, photographs or named witness interviews are needed to establish its history.

**Silence in the archive is not a debunking method.** A missing dossier cannot prove that a witness invented an event or mistook a particular object. It only shows that no matching released military file has been identified.

The reverse is equally important: absence should not be converted into a theory of suppression without evidence. The archive’s gaps have ordinary possible causes, including non-reporting, weak military relevance, decentralised paperwork, loss and inconsistent place names. Claims of deliberate concealment would require a document trail showing that a specific Cáceres report was received, classified and withheld.

## The most useful way to read Cáceres claims

The declassified collection creates a practical hierarchy for the province’s UFO history.

At the top sits Montánchez: a dated, substantial Air Force intelligence dossier with a traceable catalogue record and declassification order. Below it are incidents supported by contemporary local reporting, identifiable witnesses or other records but absent from the military archive. Lowest are stories that appear only in late retellings, mystery television or unsourced online lists.

This hierarchy does not decide what witnesses saw. It distinguishes levels of evidence. A modestly documented unexplained light may remain genuinely unresolved, while a dramatic close-encounter story may be historically weak if no contemporary source can be found.

The Cáceres record is therefore significant precisely because it is limited. Spain’s national archive does not reveal a hidden provincial wave of military encounters. It preserves one important aviation case, exposes a geographical cataloguing error and shows why official silence must be interpreted carefully. The archive strengthens the historical standing of Montánchez, but it neither validates every later Cáceres claim nor proves that the province’s unrecorded reports were without substance.

    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
